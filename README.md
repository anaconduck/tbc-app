# PulmoSense — Tuberculosis Biomarker & Clinical Risk Assessment

Aplikasi web responsif (*desktop* & *mobile*) untuk skrining risiko Tuberkulosis (TB) berbasis biomarker imunologi **TLR2** dan parameter klinis (**Riwayat Kontak, Status Gizi/IMT, Status Anti-HIV, Jenis Kelamin**) yang berjalan 100% di sisi klien (*static HTML/JS*) pada **GitHub Pages**.

- **Live App (GitHub Pages):** https://anaconduck.github.io/tbc-app/

## Menjalankan Secara Lokal

- Buka langsung `index.html` di *browser* (Laptop maupun HP), atau jalankan server lokal ringan:
  ```bash
  python serve_web.py
  ```
